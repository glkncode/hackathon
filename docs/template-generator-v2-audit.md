# Аудит Template Generator 2.0

Все десять исходников присутствуют в `data/demo`. Для воспроизводимого чтения XML и PDF используйте `scripts/audit_template_sources.py`; оригиналы только читаются. Профили закрепляют SHA-256 исходного DOCX и каждого источника правил. PDF — **учебный пример**, не действующий документ (явная маркировка каждой страницы); дата начала применения в п.12.11 — 01.11.2026. Проверка официальной актуальности вне приложения.

| Источник | Проверенное требование | Расхождение v1 / решение v2 |
|---|---|---|
| Методические рекомендации, 3.1–3.3 | Отдельный файл; удалить верхний гриф именно модуля, маркер, пояснения, примечания и варианты | v1 сохранял их; v2 удаляет только закреплённые SHA и структурными якорями элементы |
| Те же, 3.3; Инструкция, 8.7–8.8, 8.20 | Сохранить служебные зоны даты/номера/ЭП | Не заполнять регистрационные реквизиты; сравнивать защищённые XML-узлы |
| Инструкция, 8.13, 8.18, 8.19 | Утверждение создаваемого документа, приложение и полномочия отличаются от утверждения модуля | Удаляется только таблица 0 оригинала; приложение физически не присоединяется; полномочия — ручная проверка |
| Методические рекомендации, 1.2–1.3, 4.1–4.3; Инструкция, 9.16, 10.6, 10.11, 10.13 | Актуальность, проверка постоянных формулировок, общий маршрут, лингвистическая экспертиза | Предупреждения и ручные проверки, без вымышленного освобождения от процедур |
| Матрица, положения 1–3, внутренние строки 2,3,4,6,7 | Дополнение к общему маршруту, совокупность строк, «Нет» не запрещает визирование | Структурированная рекомендация с условиями, без исполнения workflow |
| Рабочая группа, прим.1–8, общие правила | Единая тема, ограниченная цель, состав, срок/действие/результат/адресат/завершение | Один источник названия, реальные строки состава, ручная проверка смысловой связи |
| Проектный комитет, прим.1–10 | Согласовать число; отмену удалить в заголовке и п.2; контроль 3→2 | Связанные фрагменты, условная обязательность реквизитов, управляемая нумерация |
| ИС, прим.1–15 | Единые имена, реквизиты готовности/разработки, выбор разработанного/измененного, даты, эксплуатационная документация | Автоматические сравнения дат, подтверждаемое основание исключения; фактические документы вручную |
| Локальный документ, прим.1–8 | Единое название, дата, подразделение, размещение, приложение, отмена | Ссылка сохраняется; отсутствие вложения явно отмечается в отчёте |
| Ответственные за ДОУ, прим.1–7 | Подразделение связано с работником; отмена условна, согласие/функции проверяются | Клонирование строк; ручная проверка согласия/функций |
| Передача, прим.1–8 и общие правила | Удаляемый источник «от …», срок, контроль подписанта; независимость только если требуется внутренними правилами | Ветви текста; отсутствие подтверждения независимости не универсальный запрет |
| Аудит, прим.1–8 | Период, число процессов, аудиторы, доступ, отчёт, план, независимость | Сравнения дат и строки; реальная независимость требует проверки |

Особенности источников: в методических рекомендациях п.4.2 перечисление переходит с 1 на 3; недостающий шаг не восстанавливается предположением. Инструкция 10.6 используется как отдельный источник общего маршрута. В преамбуле оригинала ИС несогласованные кавычки (`далее - …»)`); профиль исправляет только этот проверенный фрагмент. Комитет не содержит текстового блока подписи: выбранный подписант хранится в данных проекта и отчёте, ЭП не подменяется текстовой подписью. Акт передачи и утверждаемый локальный документ отсутствуют в исходных модулях; генератор не объявляет комплект приложений проверенным. Эти расхождения не трактуются как установленный приоритет одного источника над другим.
