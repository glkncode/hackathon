# React Template Wizard — проверка 24.10.2026

Проект: `D:\Projects\hackathon`. Адрес: http://localhost:8080. Проверка выполнялась на существующем локальном Docker Compose с PostgreSQL 17, Go, Python FastAPI и React production bundle. Использованы помеченные синтетические пользователи и семь исходных модульных DOCX из ранее проверенного backend v2. База, volumes и существующие пользовательские изменения сохранены. Commit, push, VPS и удаление volumes не выполнялись.

Архитектура и фактические контракты описаны в [template-wizard.md](template-wizard.md). Backend Go/Python и миграции 00001–00011 в этой UI-задаче не редактировались. Исходная рабочая копия уже содержала незакоммиченные изменения backend, инфраструктуры, RAG и предварительные UI-файлы; они не объявляются новыми изменениями этого этапа.

## Безопасность и restart

`security-restart` через реальный публичный API проверил чужого владельца (в том числе admin), CSRF без токена, идемпотентность повторного generate, отзыв/восстановление ACL, исчезновение черновиков из списка и отказ скачивания уже готового файла. Для четырёх готовых revision получен PASS. Отчёт: `.local-integration/template-wizard/api-verification.json`.

Сценарий restart создал частичный черновик, сохранил ответ, перезапустил только stateless api/ai-service/frontend и подтвердил ту же revision/values. Затем черновик заполнен оставшимися серверными вопросами и сгенерирован. Все четыре ранее полученных файла повторно скачались с прежним SHA. В браузере также повторно скачан существующий результат ИС после restart и reload.

Затем E выполнен полностью через UI: browser draft `af0ef0d2-c3f0-4bae-bf76-f307e9c66c72`, два сохранённых ответа и revision 3 → `docker compose restart api ai-service frontend` → reload той же страницы с revision 3 → остальные вопросы через React → результат `2898c04f-7f93-4717-b480-361c2a94db14`. Прежний результат рабочей группы повторно скачан в браузере после этого restart. PostgreSQL и volumes не перезапускались и не удалялись.

Browser ACL: после отзыва доступа результат показал «не найдены или больше недоступны», кнопка скачивания исчезла, рабочая группа и её черновики исчезли из каталога. После восстановления ACL прежняя страница результата снова открылась с кнопкой download. Права тестового пользователя восстановлены.

При дополнительных login/logout-проверках штатный Go limiter вернул HTTP 429 (10 входов с IP за 15 минут). Защита не отключалась; после окончания окна browser login второго пользователя выполнен успешно. Прямое открытие чужого draft показало 404/«не найдены или больше недоступны», приватных полей в DOM нет. После logout и входа владельцем его готовый результат снова доступен. Ownership/CSRF/ACL дополнительно проверены реальным API, а не unit mocks.
