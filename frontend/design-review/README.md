# Редизайн помощника по документам

Реализация доступна на http://localhost:8080. Обновлён только локальный frontend-контейнер с разрешения пользователя. Изменения редизайна находятся в `frontend/`; существующие изменения других задач сохранены. Коммиты и push не выполнялись.

1. **Обнаруженные проблемы.** Мелкие размеры были заданы в отдельных компонентах, навигации, подписях и элементах форм. Узкая рабочая колонка и слабая иерархия усиливали впечатление пустого экрана. Существовали разные стили кнопок, технические подписи и английское название продукта. Масштабирование через `zoom` или `transform` не применялось.

2. **Изменённые компоненты.** Обновлены общие UI-примитивы, AppLayout, Sidebar, Header, приветствие чата, карточки примеров, composer, сообщения, источники, страницы шаблонов и регистрации, поля и предупреждения Wizard, документы и загрузка, пользователи, login, результат генерации и пустые состояния. Добавлено безопасное отображение Markdown и работающая кнопка копирования ответа. Названия шаблонов отображаются из backend без подмены названиями профилей.

3. **Дизайн-система.** Токены находятся в `src/shared/styles/global.css`, общие компоненты — в `src/shared/ui/ui.module.css`. Использованы фон `#f9fcfb`, белые поверхности, мятная навигация `#eaf6f1`, основной текст `#142523`, акцент `#0b806e`, hover `#086c5e`. Основной цвет немного затемнён относительно ориентира брифа для контраста белого текста. Радиусы карточек 18 px, контролов 12 px; общие рамки, тени и focus-состояния. Шрифт — системный гротеск с кириллицей, без внешнего CDN.

4. **Русификация.** Название продукта заменено на «Помощник по документам», ответ — на «Ответ помощника», роль admin отображается как «Администратор». Приведены к русскому виду версии, подписи шаблонов, действия, предупреждения, пустые состояния, доступные названия элементов и заголовок вкладки. Настоящий логин `admin`, имена документов, UUID, API enum и исходные цитаты не переводились.

5. **Типографика.** Базовый размер 16 px, ответы 17 px, основной заголовок до 42 px, заголовки разделов 28–34 px, вспомогательные подписи от 13 px. Основные поля и кнопки около 48–50 px. Увеличены межстрочные интервалы, расстояния между блоками, размеры навигации и карточек. Ширина чата ограничена 1080 px вместе с внутренними отступами, чтобы на широком экране сохранялась удобная длина строк.

6. **Фирменная стилистика.** Реализованы светлые мятные и зелёные радиальные градиенты, крупная тёмная типографика, собственный лёгкий SVG с линиями схемы и единые иконки Lucide. Декор сосредоточен в приветствии и авторизации; ответы и формы остаются на чистых поверхностях. Отдельный титульный слайд презентации не был доступен: использованы доступное изображение и текстовый бриф. Логотипы организаторов не переносились.

7. **Адаптивность и доступность.** Sidebar 276 px, на небольшом desktop 250 px, до 900 px — drawer. Мобильные карточки идут в одну колонку; composer остаётся отдельной доступной областью. Проверены ширины 375, 390, 430, 768, 1024, 1366, 1440 и 1920 px. Исправлены выход скрытой подписи документов за границы и расширение формы регистрации длинным именем DOCX/SHA-256. Пустой чат открывается с начала приветствия; история прокручивается к сообщениям. Для широких таблиц предусмотрена локальная прокрутка. Сохранены клавиатурная навигация, focus trap мобильного меню, Escape, семантические кнопки и labels, видимый focus и reduced-motion. Настоящая экранная клавиатура телефона отдельно не проверялась.

8. **Автоматические проверки.** Финальный прогон: TypeScript и production Vite build в Docker — успешно; ESLint — успешно; Vitest — **12 файлов, 125 тестов успешно**; `git diff --check -- frontend` — без ошибок whitespace. Проверяются API transport, сессии, доступы пользователей, шаблоны, чат и прокрутка. Добавлены проверки Markdown, небезопасного HTML/ссылок/изображений и видимости приветствия пустого чата. Настроенной Playwright E2E-suite в проекте нет. Для Markdown добавлены `react-markdown` и `remark-gfm`; тяжёлый UI framework не добавлялся.

9. **Проверка настоящего приложения в браузере.** Проверены пустой чат, создание диалога и реальный вопрос, loading, ответ backend с источником, отказ без источников, история и переключение чатов, заполнение поля карточкой примера, Enter/Shift+Enter, копирование ответа и скачивание настоящей версии источника. Проверены список документов, открытие формы загрузки, каталог шаблонов и регистрация с метаданными исходного документа, экран пользователей и ошибки пустой формы создания. Вход выполнил пользователь. Учётные записи, ACL, документы и регистрации шаблонов для тестов не создавались. Новый тестовый чат с реальным ответом сохранён в истории: `50d38917-3f3a-419c-a9eb-49732ee3ab8f`.

10. **Границы проверки.** На момент проверки каталог зарегистрированных шаблонов пуст, поэтому сохранение черновика, полный Wizard, генерация и скачивание созданного DOCX не проверены на настоящем backend. Семь исходных профилей v2 сохранены; представительные поля, обязательные ошибки, даты и повторяемые строки визуально проверены на изолированном стенде. Это не функциональный E2E. Длинный Markdown с таблицами и login также проверены отдельно на стенде. В системе доступна только учётная запись администратора: сценарий member, реальные изменения ACL, создание пользователя и logout/relogin браузером не выполнялись. Существующие unit-тесты ролей и шаблонов прошли. API, AI-сервис и PostgreSQL не перезапускались действиями этой задачи; volumes не удалялись.
